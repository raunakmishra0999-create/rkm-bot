# X TOURNEYS Discord Bot

Tournament management bot for Discord servers.

## Commands

- `!ping` - Check bot latency
- `!hello` - Bot greets you
- `!serverinfo` - Get server information
- `!rkmhelp` - Show all commands

## Setup

1. Add bot token in Render environment variables as `DISCORD_TOKEN`
2. Deploy on Render
3. Invite bot to your server
